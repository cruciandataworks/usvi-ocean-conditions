    How this was built

    Three agencies, one tested pipeline, every 3 hours

    Python collectors ask NOAA's tide service, NOAA Coral Reef Watch and the CARICOOS buoy server only for what is new since the last run, and merge it into a Parquet data lake without ever creating duplicates. DuckDB and dbt turn the lake into tested tables: verified tide data replaces preliminary data when NOAA releases it, and 44 checks run before anything reaches this page. When a condition needs attention (bleaching heat stress, flooding, a feed that has gone quiet) the pipeline opens a GitHub issue and closes it again when the condition clears.

    1. 1Collect tides, water temperature and flood levels from NOAA CO-OPS
    2. 2Collect coral heat stress since 1985 from Coral Reef Watch
    3. 3Collect waves and temperature from the CARICOOS ERDDAP server
    4. 4Load the Parquet lake into DuckDB
    5. 5Model and test with dbt, including freshness rules
    6. 6Export JSON for this page
    7. 7Open, update or close alert issues on GitHub
